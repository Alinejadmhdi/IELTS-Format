# IELTS Format

Interactive IELTS Listening/Reading from screenshots.

## Free setup (recommended)

Use **Google Gemini free API** (not DashScope):

1. Key: https://aistudio.google.com/apikey  
2. Put it in `.env` (see `.env.example`)  
3. `npm run bridge` + `npm run web` → http://127.0.0.1:5173/

Full guide: **[docs/USER_GUIDE.md](docs/USER_GUIDE.md)**
